# 数字助教支持分流资料约定

资料全部是本地合成业务记录，不含真实个人信息。`term-a` 为完整版本，`term-b` 保持业务值不变而调整表行次序，用于检验分析是否不恰当地依赖到达顺序；`limited` 保留登记资料并移除一类观测，表示证据不足的版本。版本内容不可就地修改。

- `people`：业务唯一键为 `person`。
- `audits`：业务唯一键为 `person`。
- `capacities`：业务唯一键为 `site`。

score 越大表示系统判断越可能需要帮助，不保证校准。audits 是已收到的人工复核；selected_by=random 时 inclusion_probability 是对全体该 cohort 的随机抽查概率，转介补充样本的概率未知，不能混成同一个抽样权重。cohort 是连续入组批次，用于前后期验证；单人只能属于一个批次。capacities 是当前各校区可提供的人工建议名额，不影响学员主动申请资格。

字段之外不能从示例的编号顺序或随机生成规律推导业务关系。涉及权重、相关范围、模型支撑的判断必须使用明确登记的字段和业务假设。
